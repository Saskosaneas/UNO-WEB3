# UI Assets & Media Resources

This directory is designated for visual and audio assets to be used in the upcoming user interface milestones:
- **Assignment 2:** Browser-Only Uno (Vue.js frontend + Web Worker bots)
- **Assignment 3:** Multiplayer Uno (Vue.js client)

## Asset Categories & Guidelines

- **Cards & Illustrations:**
  - Card face SVGs or PNGs (Numbered 0–9 across Red, Blue, Green, Yellow)
  - Action cards (Skip, Reverse, Draw 2)
  - Wild cards (Wild, Wild Draw 4)
  - Card back designs
- **Audio & Sound Effects (Optional / UX Polish):**
  - Card deal / flip sounds
  - "UNO!" shout sound bite
  - Draw penalty sound / alert
  - Victory fanfare
- **Interface Graphics & Avatars:**
  - Player / Bot avatar icons
  - Active color indicator tokens
  - Table background textures / mats
